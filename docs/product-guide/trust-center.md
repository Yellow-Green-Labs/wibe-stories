# Trust Center

> The services we rely on to run Wibe Stories, what they do, and how your data is handled.

## Hosting and Infrastructure

[![Vercel](https://cdn.simpleicons.org/vercel)](https://vercel.com) **Vercel** — App hosting, serverless functions, edge network, and blob storage for card images and voice files.

[![Upstash](https://cdn.simpleicons.org/upstash)](https://upstash.com) **Upstash** — Redis data store for daily usage limits, rate limiting, session state, and email subscriptions.

[![Neon](https://cdn.simpleicons.org/neon)](https://neon.tech) **Neon** — Postgres database for Wibe Vault card storage (Pro users).

## Speech and Language

[![Deepgram](https://cdn.simpleicons.org/deepgram)](https://deepgram.com) **Deepgram** — Speech-to-text transcription (Nova-3) for live recordings and uploaded audio.

[![OpenRouter](https://cdn.simpleicons.org/openrouter)](https://openrouter.ai) **OpenRouter** — AI model gateway for tone rewrites. Routes each request to the best available language model.

## Payments and Email

[![Buy Me a Coffee](https://cdn.simpleicons.org/buymeacoffee)](https://buymeacoffee.com) **Buy Me a Coffee** — Payment processing for Wibe Pass purchases and gift cards.

[![Resend](https://cdn.simpleicons.org/resend)](https://resend.com) **Resend** — Transactional email delivery for Pro key recovery and occasion reminders.

## Monitoring

[![Sentry](https://cdn.simpleicons.org/sentry)](https://sentry.io) **Sentry** — Error monitoring and session replay. Data scrubbing is enabled to redact sensitive information.
